# Resume — GitHub Pages Portfolio

Este repositório contém um site simples para publicar seu currículo como uma GitHub Page.

Atenção: substitua os placeholders (Seu Nome, seu-email@exemplo.com, links) pelos seus dados reais antes de publicar.

Arquivos incluídos:
- `index.html` — Página principal (conteúdo já preenchido com o seu currículo).
- `styles.css` — Estilos.
- `script.js` — Script simples para preencher o ano automaticamente.

Como publicar (passo a passo):
1. Verifique se os arquivos estão no branch `main`.
2. Vá em Settings → Pages no repositório.
3. Em Source selecione `main` e root `/`.
4. Salve. A página ficará disponível em alguns minutos em: `https://<seu-usuario>.github.io/Resume`.

Recomendações rápidas para otimizar a página para recrutadores:
- Substitua o e-mail e os links por seus contatos reais.
- Faça upload de `resume.pdf` com uma versão em PDF do seu currículo.
- Adicione links para projetos relevantes (repositórios ou demos).
- Destaque métricas e resultados nas experiências (ex.: tempo de deploy reduzido, economia gerada, aumento de eficiência).
